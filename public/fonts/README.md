# Police Graphik

Le brief demande Graphik. Le fichier Figma utilise Inter.
Le lien du brief mène à une version d'essai à usage personnel, sans droit de redistribution web établi.
Le projet utilise Graphik si elle est installée localement, puis Inter auto-hébergée (licence OFL).
Pour un rendu Graphik identique sur tous les appareils, fournir les fichiers web et leur licence d'intégration,
puis remplacer les sources `local()` dans `src/styles/main.scss` par les fichiers autorisés.
Source du brief : https://befonts.com/graphik-font-family.html
Éditeur : https://commercialtype.com/catalog/graphik
